# Tampa Vendor Bench

A landlord's system for keeping reliable, fairly priced trades on call for Tampa rentals.

- Live page: https://shaw-arcade.github.io/tampa-vendor-bench/
- Workbook: `docs/Tampa-Vendor-Bench.xlsx` (bench, job log, triage guide, sourcing, vetting)

`build.py` regenerates the workbook. `make_site.py` regenerates `docs/index.html` from the same data. Run `build.py`, then the recalc step, then copy the workbook into `docs/`.
